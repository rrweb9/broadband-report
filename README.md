# Broadband quality report

An automatically generated report on one home broadband connection: measured line
capacity, latency, jitter, packet loss and outages.

The live report is `index.html` (published via GitHub Pages). It is a single
self-contained file - open it locally and it works offline too.

Measurements are taken on the connection itself: a quick check every 10 minutes
(pings, DNS, short transfers) and a full capacity test four times a day using
Apple's `networkQuality`. Speed figures come only from the full capacity test;
the quick check measures responsiveness, not speed. See "How this was measured"
on the page itself.

Generated by tooling in a private repository; this repo holds only the rendered
output.
